## Rules for a chapter

- **True, never fabricated.** No chapter describes a feature that does not exist as if it ships. Roadmap
  is labelled roadmap (Doctrine §3).
- **Traceable.** Every claim traces to Chapter 1's charter or a Doctrine law in [`CLAUDE.md`](../../CLAUDE.md).
- **Gated.** A chapter is "done" only when it passes the [Design Review Gate](../../FOUNDER_BIBLE.md) — the
  same five checks the code must clear.
