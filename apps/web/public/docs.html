Intent Wallet
Technical One-Pager · GIWA · GASOK

An AI-native wallet with a security layer that refuses to lose your money.

Tell it what you want in plain English. A deterministic parser turns it into a typed intent, the planner verifies it against the real world, and it signs on your device — or refuses, and tells you why. Built on GIWA (Upbit/Dunamu OP-Stack L2, chainId 91342).

The pipeline

Natural language becomes a typed intent with no model round-trip for common asks — the LLM is only a fallback. Everything is verified before a signature is even possible.

plain English→ deterministic parser→ typed intent→ planner + Sentinel→ device signature→ on-chain

Sentinel — the security layer

One rule, five expressions: when the wallet can't safely deliver what you asked, it refuses to sign — before signature, not after.

  • Address poisoning — catches a lookalike on a first-ever send, using on-chain history.
  • EIP-55 checksum — one mistyped character fails its checksum and is stopped.
  • Cumulative-drain guard — a drain split across several under-threshold sends is caught on the one that completes it.
  • Recipient never dropped — an unparsed address is never silently discarded; the wallet asks instead of guessing.
  • Undeliverable-route refusal — a route it can't finish end-to-end is refused, not attempted and lost.
The discipline is the product. Address poisoning alone: 270M attempts, 17M victims, $83.8M stolen (USENIX Security '25). A wallet should catch this before you sign.

Architecture

  • 6-layer strict-DAG monorepo — chains build, core signs. The signing core holds no chain logic; chain modules hold no keys.
  • Non-custodial — keys are generated and sealed on device (BIP-39/32/84, EVM + Bitcoin + Solana) and never touch a server.
  • Float-free money paths — every amount is exact integer math; no floating-point drift, ever.
  • 600+ tests across parser, planner, guards, chains, and the deployed API path.

Routing — a seam, not a rewrite

One RouteProvider interface picks the venue; no DEX or bridge is hardcoded. Testnet composes GIWA's on-chain AMM and the canonical bridge today; mainnet registers audited aggregators (0x / 1inch / LI.FI · Wormhole / CCTP) through the same seam — and the safety layer doesn't change. Unsupported routes are refused before signature, never faked.

Stack & deployment

  • Contracts: Solidity + Foundry (EVM); Anchor/Rust (Solana devnet twin).
  • App: TypeScript — Vite SPA (client-side signing) over a Fastify API.
  • Live: frontend on Vercel, backend on Railway. Keyed RPC is proxied server-side — no secret ships in the bundle.
